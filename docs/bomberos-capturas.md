# Material de Bomberos de Granada

Fuente: https://github.com/DavidEstevezzz/bomberosgranada.es
Revisión utilizada: d87aaa4f4313c4bcc4bcdee08d484251e7117270.

Las imágenes de `public/projects/bomberos` son renders a doble resolución de componentes del frontend original: `vite-project/src/components/Calendar.jsx`, `views/Brigades.jsx` y `views/PersonalEquipment.jsx`. Se usaron sus estilos Tailwind y Montserrat. El marco lateral y la cabecera son una presentación específica para el portfolio, no el layout original.

Se sustituyeron en memoria las lecturas de servicios por listas ficticias de parques, brigadas y equipos. El calendario recibió datos de muestra por props. No se utilizaron datos operativos, cuentas ni conexiones al backend; la captura bloqueó peticiones externas. No se modificó el repositorio remoto del cliente.

Resoluciones: calendario 2880 × 1860; brigadas 2880 × 2372; equipos 2880 × 2724. PNG para conservar la legibilidad del texto. La ficha identifica el uso de datos ficticios y permite abrir cada imagen a tamaño completo.

El contenido describe funcionalidades observadas en componentes y rutas; no atribuye cifras de impacto, disponibilidad ni rendimiento no verificadas. Esta primera ficha cubre planificación, organización y recursos; no pretende enumerar todos los módulos del sistema.
